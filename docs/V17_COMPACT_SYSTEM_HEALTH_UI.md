# v17 – Kompakter Systemzustand

- Der technische Health-Bereich der Systemseite ist jetzt ein kompaktes Accordion.
- Bei gesundem System ist es standardmäßig eingeklappt; Updates stehen dadurch direkt im sichtbaren Bereich.
- Bei Warnung oder Fehler klappt der Systemzustand automatisch auf.
- Die Detailansicht enthält weiterhin alle Dienste, Sensor-/Erreichbarkeitsdaten sowie den Hinweis auf E-Mail/Telegram-Statusabfragen.
- Update-Texte verwenden deutsche Umlaute (`Update verfügbar`, `Letzte Prüfung`, usw.).
